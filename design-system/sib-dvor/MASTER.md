# Дизайн-система «Сибирский двор» — мир «Сутки двора»

## Идея
Один зимний день на участке. Цвет страницы идёт вслед за солнцем: утро (холодный голубой) → день (снег, береста) → вечер (сумерки, янтарь) → ночь (индиго, тёплые окна). Орнамент хантыйского сукна — разделитель и верхняя кромка карточек.

## Шрифты (локально, docs/vendor/fonts, OFL, латиница + кириллица)
- Literata (opsz 48, 300–600, + курсив) — заголовки, цитаты. «двор» в H1 — курсив, красный.
- Onest (100–900) — текст и интерфейс.
- Unbounded (300–700) — часы 09:40, цифры рейтингов, надзаголовки капсом (letter-spacing .08–.12em).

## Компоненты
- Демо-плашка 32 px (44 px на ≤560), плавающая шапка-пилюля: sticky, height 0, внутри top 12px; над тёмными секциями — тёмная.
- Кнопки: красная заливка / контур, высота 50, радиус 999.
- Панель главы «Сутки»: бумага 90 %, кромка-орнамент 10 px сверху; вечером и ночью — тёмная.
- Карточки «Места»: sticky-стопка, затемнение нижней после того, как следующая прошла 38 % экрана.
- Подсветка зон: маска Object Index (map-mask.png, R = индекс × 10). Светлый кадр — красный контур + янтарная заливка 18 %; тёмный — янтарный контур.
- Чек: бумага #f6f1e4, зубчатый край, моно-цифры Unbounded.

## Движение
- Hero: медленный наезд 1.09 → 1 за 26 с, появление текста лесенкой 0.09 с.
- «Сутки»: 600vh, sticky, холст с пролётом из Blender (440 кадров: docs/assets/seq2/d 1600×900 и seq2/m 720×1280). Глава = 25 % прогресса: первые 36 % — удержание (кадры 1–20 / 140–160 / 280–300 / 420–440, лёгкий дрейф), дальше перелёт к следующей зоне (20–140, 160–280, 300–420, ≈10 px прокрутки на кадр), свет меняется вместе с ним; соседние кадры смешиваются. Кадры грузятся после load: ключевые, затем шагами 32/16/8/4/2/1. Колесо мыши — плавная прокрутка (Smooth в app.js).
- Без GSAP и при prefers-reduced-motion сайт работает: сцена переключается без анимаций.

## Источники кадров
Blender, сцена sib_dvor_blockout.blend, камера Cam_Map (орто 262, азимут 165°, наклон 38°), функция времени суток — текст `sd_time` внутри .blend. Крупные планы: Cam_Ski, Cam_Ethno, Cam_Banya, Cam_Cafe. Пролёт: Cam_Fly + Fly_Target, текст `sd_fly` (KEYS — ключи камеры, LIGHT — ключи света), дальняя тайга — коллекция FarForest и Ground_Far.
