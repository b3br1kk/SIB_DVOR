# «Сибирский двор» — демо-концепт сайта

Нефтеюганск, ул. Ленина, 7: база отдыха, бани на дровах, кафе «Сибирь» и Юганская этнодеревня.
Мир «Сутки двора»: прокрутка ведёт солнце над 3D-макетом участка — утро после лыжни, день в чуме, вечер в бане, ночь в кафе.

- Сайт: `docs/` (GitHub Pages), без внешних CDN: GSAP и шрифты в `docs/vendor/`.
- Кадры — рендеры Blender (`sib_dvor_blockout.blend` на ПК автора), маска зон `docs/assets/img/map-mask.png` (R = Object Index × 10).
- Тексты: `copy/index.md`, дизайн-система: `design-system/sib-dvor/MASTER.md`.
- Проверка: `python3 tools/check.py` (Playwright, 1440×900 и 390×844), `python3 tools/interact.py` (карта и сборщик).

Демо, не официальный сайт. Факты — из открытых источников на 20.11.2026.
